# ArmVault

แอปออมเงินแบบ "เพิ่มวันละ 1 บาท" (PWA ติดตั้งลงหน้าจอหลักได้ ใช้ออฟไลน์ได้) ข้อมูลเก็บในเครื่อง (localStorage) ไม่มีเซิร์ฟเวอร์

## ขึ้น GitHub Pages
1. สร้าง repository ใหม่บน GitHub (เช่น `armvault`) แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `icons`)
2. ไปที่ Settings → Pages → Source: เลือก `Deploy from a branch` → Branch: `main` / `(root)` → Save
3. รอ 1–2 นาที แล้วเปิด `https://<ชื่อผู้ใช้>.github.io/armvault/`
4. บนมือถือ: เปิดลิงก์ด้วย Chrome/Safari → เมนู → "ติดตั้งแอป" / "เพิ่มลงหน้าจอหลัก"

## ย้ายข้อมูลจากเวอร์ชันเดิม
ข้อมูลเก็บแยกตามโดเมน ต้องสำรองแล้วกู้คืน: เวอร์ชันเดิม ตั้งค่า → สำรองข้อมูล → ดาวน์โหลดไฟล์/คัดลอกข้อความ → เวอร์ชันใหม่ ตั้งค่า → สำรองข้อมูล → กู้คืน

## ไฟล์
`index.html` แอปทั้งหมด · `manifest.webmanifest` · `sw.js` (ออฟไลน์) · `icons/` ไอคอนแอป

## ข้อจำกัด
แจ้งเตือนบนมือถือทำงานเมื่อเปิดแอปไว้ (หรืออยู่เบื้องหลัง) เท่านั้น เพราะไม่มีเซิร์ฟเวอร์ส่ง push
